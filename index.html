A look inside

I

What it does

Books of contacts

Keep one or more address books. A contact holds a name, phones, emails, messaging handles (Signal, Telegram, Matrix…), addresses and notes. Search across them. Add, edit and delete offline; changes merge when your devices meet.

Share a book

Every book has a kith://join link and a QR code. Open the link or scan the QR on another device and the book syncs there too: your phone and desktop, or a household's shared list.

vCard in and out

Paste vCards to import your existing contacts, and export one contact or a whole book. A contact's Loam key travels in an X-LOAM-KEY field. Support is basic for now: paste/copy text, no photos.

Phone & desktop

An Android app and a Basecamp module that fold the same signed events the same way, so a book reads identically on both. Each edit is signed, so you can see which device or identity wrote it.

II

A contact can carry a Loam key

Besides a name and a number, a contact can hold a Loam identity: the public key and address that sign that person's writes in Loam apps. Today that is a verifiable note on the contact. Later it should let other apps use Kith as a picker, for example to make someone an editor of a Scala calendar or an admin of a QAKU room. That integration is planned and not built yet.

How to get someone's key into a contact today:

  1. Import their vCard. If it has an X-LOAM-KEY line (for example a contact exported from someone else's Kith), the key comes in with it. Android + desktop
  2. Type or paste it in. In the desktop contact editor, switch on the Loam identity and fill in the address and public key. On Android the field is read-only for now. desktop
  3. “Add author to contacts”. The desktop core has the call that turns the author of an event (say, in a shared calendar) into a contact, but no app has a button for it yet. planned
  4. Scan their key as a QR code. The QR scanner only joins books for now. not yet

A key that arrives any of these ways is marked unverified. Check it with the person some other way; on the desktop you can then tick “verified”.

III

How it works & who can see what

The join link is the key. Anyone who has a book's kith://join link (or its QR code) can read and change every contact in it. There is no way to remove someone yet. To cut someone off, make a new book and share it only with the people who should keep it. Send links only over a channel you trust.
  • Your devices hold the data. Contacts live in local storage on your phone and in Basecamp on your desktop. There is no Kith server and no account.
  • Sealed before it leaves. Every edit is encrypted (AES-256-GCM) with the book's own random key before it is sent. The key travels only inside the join link.
  • Signed by its author. Edits are signed with secp256k1: on the desktop with your loam_core identity, on the phone with a per-device key kept in Android's secure storage.
  • What the network sees. Edits travel over the Logos Delivery (Waku) network. Relays and store nodes see ciphertext on a per-book topic, plus its timing and size, but not your contacts. Store nodes may keep that ciphertext for a while.
  • How devices catch up. When devices of the same book are online together they compare what they have and send each other what's missing. Edits made offline go out the next time they meet.
  • Loam recommended, not required. On Android, Loam runs one shared node for all your Logos apps, with Bluetooth as an experimental, Android-only option. Without Loam, Kith starts its own node. On the desktop, Kith uses loam_core, which Basecamp installs for you.

Get Kith

Android · F-Droid

Add the repo, install Kith

Scan with the phone, or open the link on it:
apps.vpavlin.xyz/fdroid/repo

  1. Install F-Droid if you don't have it.
  2. Add the repo with the QR or link above. Check that the fingerprint matches:2373710A76ACB09F287F053E99E533F9D3685529C44E9027CDBC79B1DC0C9105
  3. Search for Kith and install it.
  4. Recommended: also install Loam from the same repo, so all your Logos apps share one node. Without it, Kith runs its own.
  5. Create a book, or tap join and paste or scan a kith://join link.

64-bit ARM (arm64) phones only.

Desktop · Logos Basecamp 0.2.x

Add the repo, install Kith

  1. Open Basecamp's package manager and add this package repository:
    https://apps.vpavlin.xyz/logos-repo.json
  2. Install Kith (package kith_ui). It pulls in the kith core and loam_core automatically.
  3. Open Kith, create a book and choose which identity signs it.
  4. To use the same book on your phone, open its share view and scan the QR code with Kith on Android.

Supported: Basecamp 0.2.x. Basecamp 0.3 support is coming.

V

Status & limitations

Kith is an early preview. The basics work on both platforms, but it hasn't had much use yet. Don't make it the only copy of contacts you can't lose; export a vCard now and then.

Not there yet

  • Removing a member or rotating a book's key: no revocation yet.
  • Keycard signing: edits are signed with a device or loam_core key, not on a Keycard yet.
  • Scala / QAKU integration (pick a contact, “add author”): planned.
  • Device pairing that doesn't hand over the whole book key: designed, not built.
  • vCard is basic: no photos, no line folding, paste/copy only.

Good to know

  • Android: arm64 only. Loam recommended; Bluetooth via Loam is experimental and Android-only.
  • Desktop: Basecamp 0.2.x. Basecamp 0.3 support is coming.
  • Sync is peer to peer: a device catches up when another device of the book is online.
  • Design notes and plans are in the ADRs.

Current public builds: Android 0.1.5 · Basecamp kith_ui 0.2.5 + kith 0.2.4. Install the latest from the repos above.
